# Corrupted Files Project — Easy Edition

A simplified offline archive containing **443 unique incidents** from Greece and the USA.

## Start

```bash
python START.py
```

In Termux:

```bash
pkg install python -y
python START.py
```

## What is included

- `START.py` — the only program you need to run.
- `Data/incidents.json` — one compact incident database.
- `Data/image_credits.json` — attribution for downloaded event images.
- `Media/` — all unique images used by the reader.

The old maintenance tools, database shards, scattered TXT files, CSV reports, dashboards, and per-incident metadata files were removed. Repeated long-form methodology templates were also removed from the readable database.

The archive still contains historical and political material that may include disputed claims. Source links and evidence labels should be checked before using a record as a formal reference.
