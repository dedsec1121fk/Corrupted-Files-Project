DATABASE STRUCTURE / ΔΟΜΗ ΒΑΣΗΣ

Each JSON file contains a list of entries. Each entry should represent one case/event.

Recommended fields:
- id: stable unique ID.
- title: bilingual title.
- country: USA or Greece, bilingual where useful.
- year: event year.
- category: corruption, intelligence, disaster, surveillance, social control, UFO/UAP, psychological operation, etc.
- evidence_level: honest evidence label.
- article: full long-form article.
- proof_dossier: records, documents, witness types, contradictions, missing evidence.
- source_trail: public sources and research trail.
- reading_report: neutral reader conclusion and what remains uncertain.
- images: local media paths.

Rules:
1. One event = one record.
2. Do not merge unrelated cases only because they happened in the same year.
3. Do not repeat the same boilerplate in every file.
4. Keep English and Greek fields aligned.
5. Keep disputed material labeled as disputed.
6. Keep local images referenced relative to the project folder.
7. Prefer original SVG cover cards over copyrighted news photos.

Κάθε αρχείο JSON περιέχει λίστα εγγραφών. Κάθε εγγραφή πρέπει να αντιστοιχεί σε μία υπόθεση/γεγονός.

Κανόνες:
1. Ένα γεγονός = μία εγγραφή.
2. Μην ενώνεις άσχετες υποθέσεις μόνο επειδή συνέβησαν την ίδια χρονιά.
3. Μην επαναλαμβάνεις το ίδιο γενικό κείμενο παντού.
4. Τα αγγλικά και τα ελληνικά πεδία πρέπει να παραμένουν παράλληλα.
5. Το αμφισβητούμενο υλικό πρέπει να δηλώνεται ως αμφισβητούμενο.
6. Οι εικόνες πρέπει να αναφέρονται με τοπικές σχετικές διαδρομές.
7. Προτίμησε πρωτότυπες κάρτες SVG αντί για φωτογραφίες ειδησεογραφικών μέσων με πνευματικά δικαιώματα.
